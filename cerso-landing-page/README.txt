# Cerso — Landing Page

A modern, responsive landing page designed and developed for **Cerso**, a web development company focused on delivering clean, affordable, and functional digital solutions for small and growing businesses.

## ✨ Overview

The Cerso landing page combines an editorial visual style with modern web design principles, using Cerso's navy brand identity, photography, layered cards, and subtle interactions to create a polished and professional digital presence.

The website is designed to communicate Cerso's services, approach, and value proposition while providing potential clients with a clear way to get in touch.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile
* Cerso branded visual identity using `#0d1b2e`
* Modern editorial-style hero section
* Asymmetric photographic layouts
* Frosted glass UI cards
* Smooth hover interactions
* Scroll-based reveal animations
* Services showcase
* Why Choose Cerso section
* Four-step development process
* Client testimonial section
* Get a Quote contact form
* Responsive navigation
* Direct email and LinkedIn links

## 📌 Sections

### Hero

Introduces Cerso with the core value proposition and primary call-to-action.

### About Cerso

Explains Cerso's focus on creating affordable and functional digital solutions for small and growing businesses.

### Services

Showcases four core services:

* Web Development
* Management Systems
* Digital Presence
* Custom Solutions

### Why Choose Cerso

Highlights Cerso's key advantages:

* Affordable Solutions
* Fast Delivery
* Clean & Modern Design

### Our Process

A simple four-step workflow:

**Discuss → Design → Develop → Deliver**

### Testimonials

Includes client feedback to communicate trust and the quality of Cerso's work.

### Get a Quote

A client enquiry form collecting:

* Name
* Email
* Business Name
* Service Needed

### Footer

Contains Cerso branding, contact information, LinkedIn, and copyright information.

## ▶️ Running Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cerso-landing-page.git
```

Navigate into the project:

```bash
cd cerso-landing-page
```

Open `index.html` directly in a browser, or use **VS Code Live Server** for local development.

Alternatively, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
